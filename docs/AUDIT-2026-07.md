# nflreadts Comprehensive Audit — July 2026

Audit of `@nflverse/nflreadts` v0.3.0 against nflreadr **1.5.1** (CRAN, 2026-04-13) and nflreadpy **0.1.5** (2025-11-19), plus a live smoke test of every loader against current nflverse-data release assets (2026-07-02).

## 1. Local health (good)

- 800/800 unit tests pass; typecheck and lint clean; build clean (66KB ESM / 68KB CJS).
- Branch `work-for-v0.4.0`, clean tree.
- Published: `@nflverse/nflreadts` 0.3.0. The old unscoped `nflreadts@0.1.1` should be npm-deprecated with a pointer to the scoped package.
- `@nflverse/types` was **never published** (npm 404). Local repo `nflverse-types` is canonical; `nflverse-types-package` is a non-git duplicate whose `tests/` should be absorbed, then the folder deleted.

## 3. Upstream changes we must absorb (2025-2026)

1. **Player stats rebuild (nflreadr 1.5.0):** one combined file per summary level from `nflfastR::calculate_stats()`. `stat_type` (offense/defense/kicking) is deprecated; `summary_level` (`week`/`reg`/`post`/`reg+post`) now selects the **file** (`regpost` in filenames). Client-side aggregation in `player-stats.ts` becomes obsolete. New release tag `stats_team` + `load_team_stats()` sibling.
2. **Participation:** NGS participation ended after 2022. FTN donates 2023+ under **CC-BY-SA 4.0 (attribution required)**, delivered only after each postseason — cap default season at current-1 (nflreadpy does).
3. **Players v2 (1.5.0):** rebuilt players table, removed/renamed columns — `PlayerRecord` needs a schema pass.
4. **Depth charts (1.5.0):** now date-level (incl. preseason), ESPN-sourced — `DepthChartRecord` needs a schema pass.
5. **qs removed (1.5.1):** never supported here; fine. Valid formats: parquet, rds, csv(.gz).
6. **Season flip (1.5.1):** `most_recent_season()` flips the **Wednesday** after Labor Day. Check `getCurrentSeason()` in `datetime.ts` matches.

## 4. Parity gap vs nflreadpy (the port target)

nflreadpy ships 24 loaders; nflreadts has 8 (4 broken). Missing 16:

| Loader              | Asset                                              | Complexity |
| ------------------- | -------------------------------------------------- | ---------- |
| `loadTeamStats`     | `stats_team/stats_team_{level}_{season}`           | Low (mirror of player stats) |
| `loadRostersWeekly` | `weekly_rosters/roster_weekly_{season}`            | Low        |
| `loadDraftPicks`    | `draft_picks/draft_picks` (single file)            | Low        |
| `loadCombine`       | `combine/combine` (single file)                    | Low        |
| `loadInjuries`      | `injuries/injuries_{season}`                       | Low        |
| `loadContracts`     | `contracts/historical_contracts` (single file)     | Low        |
| `loadSnapCounts`    | `snap_counts/snap_counts_{season}`                 | Low        |
| `loadNextgenStats`  | `nextgen_stats/ngs_{passing\|receiving\|rushing}`  | Low-med (stat_type arg) |
| `loadOfficials`     | `officials/officials` (single file)                | Low        |
| `loadPfrAdvstats`   | `pfr_advstats/advstats_{week\|season}_{type}`      | Med (2 args) |
| `loadTrades`        | `trades/trades` (single file)                      | Low        |
| `loadFtnCharting`   | `ftn_charting/ftn_charting_{season}`               | Low        |
| `loadFfPlayerids`   | dynastyprocess repo                                | Low        |
| `loadFfRankings`    | dynastyprocess repo (`draft`/`week`/`all`)         | Low        |
| `loadFfOpportunity` | ffverse/ffopportunity releases                     | Med        |

nflreadpy deliberately skips `load_espn_qbr` and nflreadr's dictionaries/cleaning utilities; we adopt the same scope for parity, then decide extras later. Utility parity worth adding: `getCurrentWeek()`, `mostRecentSeason()` (Wednesday flip), team-abbr/player-name mapping tables.

## 5. Work plan (v0.4.0)

- **A — Fix the four broken loaders** (URLs, semantics, schema types), update mocks, re-smoke live. `loadSchedules` becomes load-once-filter-seasons; `loadPlayerStats` drops client-side aggregation for per-level files.
- **B — `@nflverse/types`:** absorb tests into the git repo, verify build, publish 0.1.0, make nflreadts depend on it (ROADMAP §8.0), delete the duplicate folder.
- **C — Parity loaders:** the 15 missing loaders above + `loadTeamStats`, each with types, mocked tests, and a live-smoke entry.
- **D — Guardrails + polish:** opt-in live integration test (env-gated) + scheduled CI canary so asset drift can never hide behind mocks again; default format parquet (match nflreadpy); season-flip check; npm-deprecate unscoped `nflreadts`; README/ROADMAP refresh; publish 0.4.0.
